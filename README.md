# README

Dit is een lesmodule bedoeld als aanvulling op de natuurkunde lessen voor VWO bovenbouw. De website is opgezet met de "TU Delft starterkit for open publishing with Jupyter Book". Gebaseerd op o.a. het onderzoek op de TU Delft.

De module sluit vooral aan op de quantummechanica leerdoelen in de syllabus. In het 'nulde' hoofdstuk wordt de benodigde voorkennis nog herhaald

## 🕵 Waar vind ik de module
Deze is gepubliceerd met github pages op
[https://svanderschot.github.io/2d-materials/](https://svanderschot.github.io/2d-materials/)


## 🏁 Doel
Het doel van de module is natuurkunde leerlingen kennis laten maken
